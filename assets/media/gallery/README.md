# Gallery photos

Store new albums under `YYYY/YYYY-MM-event-slug/`. Keep the album slug stable after publication. Use `01-`, `02-`, `03-` prefixes for display order, followed by the original image identifier.

The public album list, dates, cover, and captions are maintained in `data/gallery.yaml`. Dates use `YYYY-MM` when only a month is specified. List photos in the intended display order and set the cover to the first photograph.

Upload web-ready JPEG/PNG copies here. Keep camera originals, editable sources, original filenames, source-to-web mappings, and publication records in the lab photo archive. Do not overwrite camera originals with resized copies.
